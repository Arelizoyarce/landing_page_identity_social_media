# landing_page_identity_social_media

Landing Page para dar visibilidad a una empresa de marketing digital, construida como una **Single Page Application (SPA)**.

Una **SPA (Single Page Application)** es una aplicación web que carga una sola página HTML y actualiza dinámicamente su contenido sin recargar la página completa. Esto permite una experiencia de usuario fluida, rápida y sin interrupciones entre secciones.

---

## 🌐 ¿De qué trata esta aplicación?

Este proyecto es una landing page diseñada para mejorar la presencia digital de una agencia de marketing. Está dividida en varias vistas que representan secciones clave del sitio, cargadas dinámicamente según la navegación del usuario.

---

### 🏠 Inicio (`/`)

Presentación general de la marca con un mensaje destacado, imagen de portada e invitación a explorar más.


---

### 👥 Nosotros (`/aboutus`)

Sección que describe quiénes somos, nuestra misión, visión y valores. Busca generar confianza con el usuario.


---

### 💼 Servicios (`/services`)

Detalle de los servicios que ofrece la empresa, como branding, manejo de redes sociales, diseño de contenido y campañas publicitarias.


---

### 🎨 Portafolio (`/portfolio`)

Galería visual con ejemplos de trabajos previos, resultados y casos de éxito. Ideal para mostrar la experiencia profesional.


---

### 📬 Contáctanos (`/contact`)

Formulario interactivo para que los usuarios puedan dejar sus datos y un mensaje. Incluye validaciones y contador de caracteres.


---
